## Local Checks

Run the relevant checks before opening a pull request:

```bash
cd client
npm install
npm run build
npm run lint
```

```bash
cd server
npm install
npm test
```

## Scope

Preserve Firebase Authentication, Google sign-in, MongoDB, cart and stock reservation logic, Razorpay server verification, Shopora Membership, Shopora Rewards, fitness tools, workout features and admin authorization unless your change intentionally updates that area.

Do not commit secrets, real `.env` files or generated build output.
