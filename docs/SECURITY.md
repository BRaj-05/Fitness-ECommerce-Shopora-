# Shopora Security Notes

Shopora uses Firebase Authentication, Firebase Admin token verification, MongoDB, and Razorpay server-side signature verification.

Do not commit secrets or real `.env` files. Keep server-only credentials such as Razorpay secrets, Firebase Admin private keys, SMTP passwords, MongoDB URIs and Cloudinary secrets out of the React client.
