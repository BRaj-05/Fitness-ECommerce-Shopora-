# Shopora Implementation Notes

Shopora is a React + Vite + Tailwind client with a Node/Express API backed by MongoDB. It includes Firebase Authentication, Google sign-in, Razorpay-verified product payments, Razorpay-backed Shopora Membership, Shopora Rewards, fitness tools, plans, workouts and admin reporting.

## Current Highlights

- Premium storefront and admin dashboard
- Searchable recent transactions
- Payment invoice route with browser print / Save as PDF
- 30-second admin dashboard polling
- Quick Find with `Ctrl/Cmd + K`
