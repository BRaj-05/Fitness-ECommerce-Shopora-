# Shopora Code of Conduct

## Our Pledge

Shopora is intended to be a respectful and welcoming project for developers and users of all backgrounds and experience levels.

Contributors, maintainers, and participants are expected to interact professionally, respectfully, and constructively.

## Expected Behavior

Positive behavior includes:

- respecting different opinions and experiences
- giving constructive and actionable feedback
- welcoming new contributors
- taking responsibility for mistakes
- keeping technical discussions focused on the work
- respecting privacy and personal boundaries

Unacceptable behavior includes:

- harassment, threats, or discriminatory language
- personal attacks or sustained hostile behavior
- publishing another person's private information without permission
- sexualized or otherwise inappropriate conduct
- deliberate disruption of project discussions
- conduct that would reasonably be inappropriate in a professional engineering environment

## Scope

This Code of Conduct applies to Shopora project spaces, including issues, pull requests, discussions, code reviews, and official project channels.

## Enforcement

Project maintainers may edit, reject, close, or remove contributions and interactions that violate these standards.

For sensitive conduct concerns, contact the repository owner through a private contact method available from:

- GitHub: https://github.com/BRaj-05
- LinkedIn: https://www.linkedin.com/in/raj-basant/

Do not publish sensitive personal information in a public issue.
